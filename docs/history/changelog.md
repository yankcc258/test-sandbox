# 沙盒更新记录（v23–v36）

2026-11-04 整理目录时，从 README 原样移到这里。每一版的完整说明和验证在各区域的文档里（`docs/laboratory/`、`docs/recall/`、`docs/workstation/`、`docs/starfield/`）。更早的记录见 [v17 之前的完整记录](review-sandbox-v17.md)。

**v36**：v36 已按最新反馈放大文字与观察模型，调整目录间距，并加入静止的学习页测量纹理。详见 [v36 当前交接](../laboratory/laboratory-observation.md)。

**v35**：采纳露娜小样的测量环细针流与右上方统一入口，按预计到达时间分派构件，让底座与坐标轴先搭；飞行时保持细针，最后 20% 落位过程再展开成目标形状，无用薄片回环。同章调参保留已有构件，仅对新增与移除部分补入、退回。保留 v34 速度连续的 Hermite 运动、材质与软阴影，开始学习不等待或重播组装，阅读停止持续绘制；不搬入小样工具条或无限动画循环。移除三维中重复的 85 块题目状态片，章节文字旁的 DOM 状态刻度保留，模型构件数量仍不代表学习成果。详见 [v35 比对与整合记录](../laboratory/laboratory-observation.md#luna-handoff-v35)。

**v34（历史，基础延续）**：展开与流星组装采用保留当前可见位置、速度的连续五次曲线，途中偏移连续过渡，快速反向或换章从当前状态衔接；进入正文和调整窗口仅改变画面布局，不重启组装。尾迹收短，观察物细化底座、支撑和紧固件，象牙材质与钛金属按构件角色分开，加入轻倒角与软阴影；数学面积仍保留精确边界。当时露娜另做的独立流星小样尚未整合，其独立页面在 v35 仍保留。历史验证见 [v34 记录](../laboratory/laboratory-observation.md#validation-v34)，不代替 v35 验收。

**v33（历史，功能延续）**：螺旋承载六学科目录，其中数学 5 章、物理 1 章、化学 11 章有真实内容；计算机科学、生命科学、地球与空间仍是规划入口。选章后构件沿流星轨迹组装观察对象，“开始学习”立即可用。数学五章各有专属互动，包括与偏导数原例题一致的 `f=x²y` 曲面；其余章节采用中性档案构件预览，不代表科学模型。目录题目状态片按原题计数，与模型组装构件分开。背景改为淡测量环与细刻度，去掉墙架；目录缓慢流动，阅读时静止。阅读完成由用户手动标记，题目只保留最近结果，草稿与访问日志仅存在当前页面；没有到期推断或正式进度同步。历史验证见 [v33 记录](../laboratory/laboratory-observation.md#validation-v33)，不代替 v35 验收。

**v32（历史）**：当时将主站 `math-partials`“偏导数与全微分”完整正文、4 道数值题和 1 道多选题放入独立沙盒。数学目录列出真实 5 单元，当时仅开放这一章。桌面采用左目录、宽正文、右侧可折叠观察区；手机默认收起观察区。草稿、最新判题结果和阅读位置只保留在本页，刷新清空。马鞍仅作几何示意，另有本章 `f=x²y` 的可调数值算例；当时的暗墙、测量架与底脚在 v33 已替换。未修改主站。历史范围和验证保留在 [交接记录](../laboratory/laboratory-observation.md#luna-handoff-v32)。

**v31（历史）**：螺旋沿切向弧线舒展为三条前后错落的连续薄片曲带，展开与收拢采用保留速度的可逆阻尼，章节入口不等待动画结束。观察物精修象牙白表面、钛金属边缘和固定件，降低填光以保留暗部与结构层次。当时的课程布局讨论在 v32 落地一章，v33 扩为 17 章快照；正式数据接线仍未实现。

**v30（历史）**：新增独立的 `laboratory/` 学科观察入口，保留三叶结薄片主体。第一次点按聚焦数学，第二次展开观察对象；可切换曲面、切平面、水平截面，阅读同层的 3 篇原创数学示例讲义。手机阅读时保留模型，支持关闭动效与无 WebGL 降级。当时未接正式课程、学习数据或第四层 Agent，也未扩展生命科学课程。详见 [大螺旋学科观察](../laboratory/laboratory-observation.md)。

**v23 动画（露娜）**：

- **区域竖井**：三个区域像一栋楼的三层（2F 工作台、1F 实验室、B1 复习区），从「前往区域」切换时坐同一条竖井，右侧有楼层表。
- **纸飞机**：点窗台上的纸飞机，它一路换代飞进星空，这段飞行也是星空页的载入画面。
- **平板**：点平板就像低头看着桌上的它。屏幕在真实的四个角里开机，个人终端就显示在屏幕里，带状态栏和玻璃反光；手机上竖着看。
- **纸飞机的十代飞行器**（v25）：热气球、飞行者一号、圣路易斯精神号、DC-3、X-1、协和式、土星五号、航天飞机、长征二号F。

说明见 [docs/workstation/region-motion.md](../workstation/region-motion.md)，给 Codex 的工作台修改清单见 [docs/workstation/workstation-feedback.md](../workstation/workstation-feedback.md)。
