## 已确认的视觉方向

从球壳内部的检修栈道看恒星。左侧跨出画面的厚重采能结构挡住恒星一角；右侧球壳内壁弯向远方，面板、桁架与沟槽逐级缩小；栈道上一个极小的人提供尺度。金色掠射光，暗金属与克制的冷色维护灯。保留蓝本的空间关系，不改成外部全景球体、漂浮圆环、戴森群或太阳系示意图。

原始蓝本与完整生成记录见 [素材归档](../../exhibits/dyson/assets/README.md)。

## 当前实现与边界

- **动态概念观测台**：原图作为投射底图，WebGL2 局部纹理流动、日珥亮度变化、球壳缓慢半影与暖色反光。结构与栏杆遮罩保持刚性。没有伪造采能板三维转动。
- 固定观测台的全景 / 恒星 / 内壁取景、有限拖动与方向键微调、Home 复位、暂停、纯净画面、全屏（浏览器支持时）。H 隐藏，Esc 或“显示界面”恢复。
- 镜头切换与视觉时钟分离。暂停时仍可取景，但恒星和光影时间不前进。离屏、后台停止循环；回到观测区恢复。减少动态效果偏好与 `?motion=0` 初始暂停。
- 不支持 WebGL2 时显示原图；上下文丢失暂切静帧、恢复后重建资源；载图失败有文字提示。
- 像素预算上限约 250 万，设备像素比最多 1.6。以 PC / iPad 为主，iPad 竖屏用 4:3 观景区留住栈道与星体关系。
- 本版是**基于影像的动态设想，不是完整三维球壳或自由飞行模拟**。恒星比例、观察距离、日珥、阴影均是电影化设计；下方能源模型与影像尺度独立。PNG 投射没有浮点 HDR 渲染管线。

## 工程估算

恒星光度取 IAU 2015 太阳标称光度 3.828 × 10²⁶ W；AU = 149597870700 m；σ = 5.670374419 × 10⁻⁸ W m⁻² K⁻⁴。依据：[IAU B3](https://arxiv.org/abs/1510.07674)、[CODATA 2018](https://srd.nist.gov/jpcrdreprint/5.0064853.pdf)。

参数 R 是球壳半径，f 是有效采光覆盖率。F = L/(4πR²)，A = f4πR²，P = fL。假设完全吸收，等面积黑体表面向外辐射全部截获功率，则 T = (F/σ)^(1/4)。半径增为两倍，通量降至四分之一，温度除以 √2；改变覆盖率只改变采光与辐射面积，不改变该理想模型的平衡温度。

忽略反射、能量存储、内部回照、结构强度与动力学稳定性。此公式不证明一层刚性球壳可建造。参数只改下方模型，不把蓝本中的艺术比例标成真实物理尺度。

## 检查与复现

2026-11-12 本机结果：全仓 `npm run check` 通过；以下五组浏览器检查通过（桌面、iPad 横屏、iPad 竖屏、减少动态效果、无 WebGL）。图形上下文恢复检查额外验证画布保持原分辨率，防止隐藏时量成 1×1。纯静帧可停住每个像素；离线 HTML 已用 `file:` 地址验证，无需本地服务。现场录屏为 9 秒实际画布输出。

- `npm run check` 包含 `scripts/check-dyson.mjs`：能量守恒、反平方关系、温度尺度、覆盖率与边界参数。
- `scripts/check-dyson-browser.mjs`：真实 Chromium GPU 帧变化与暂停像素一致性；三档取景、键盘/触摸、隐藏恢复、能量控件、离屏停止、上下文恢复、无 WebGL 降级与减少动态效果。
- 输出目录通过 `DYSON_OUTPUT` 设置；浏览器通过 `PLAYWRIGHT_PATH` 与 `BROWSER_CHANNEL` 指定。可用 `PREVIEW_ROOT` 指向本仓库，沿用本地文件路由，不依赖常驻 localhost 服务。
- 浏览器尺寸：桌面 1600×1000、iPad 横屏 1194×834、竖屏 834×1194。iPad 是 Chromium 触摸 / DPR 仿真，尚未在真机 Safari 验证。
- 首页缩略图来自实际观测台浏览器帧，蓝本原图另行归档。
