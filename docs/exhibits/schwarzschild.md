## 影像增强：发光的气体盘与高动态范围（2026-11-11，猫猫）

Yank 让我看了电影版之后提了「为了视觉和震撼感需要增加什么」，然后让我来改。**只改电影模式（开场页和探测器航程）的上色和成像；轨道、光线追踪、频移公式、镜头编排、外部观察模式都没动。** 改了特蕾莎负责的 `shader.js`、`cinema.js`、`app.js`（各几处），没有碰 `flight.js`、`orbit.js`、`mission.js` 和检查脚本。分支 `exhibit/schwarzschild-hdr`，基于 `c8bc7ce`。

- **盘从不透明的板变成半透明的发光气体**（`shader.js` 的 `disk()` 和 `trace()`）。几何上仍是同一张无限薄的赤道面；区别是光线穿过盘面时只被挡住一部分（`cover`，由纹理浓淡和半径决定：里面厚、外面稀），然后继续追踪，后面的像按透过率叠加。外沿不再在最后 2 r_s 一刀切，从约 6 r_s 起越来越稀，边界跟着纹理起伏；内沿仍在 ISCO。外部观察和光路诊断（`u_debug`）照旧在第一次碰到盘时停止，所以 GPU / CPU 的光路分类对照不受影响。
- **色温层次拉开**（示意）。电影模式的色温从 `2900 K · f^0.25 · g` 改为 `4300 K · f^0.42 · g`：内沿黄白、外沿暗红。频移 g 和亮度的 g⁴ 照常乘上去，没有改。
- **贴近时的细丝**。镜头离盘面某一点 8 r_s 以内时，逐渐加入两层沿转动方向拉长的细纹（连续的平面方向坐标，没有角度接缝），掠过盘面时不再是一片平滑的渐变。
- **高动态范围成像层**（`cinema.js` 的 `createHdrCinema`）。能往半浮点纹理里画的设备上，着色器只做曝光、交出线性光（`u_hdr`），由成像层取出超过白点的部分做五级辉光，再过胶片曲线。所以辉光的能量来自画面里真正亮的地方：内沿、迎面转来的一侧、高阶像和光子环。迎面的光被 g⁴ 放大几十上百倍，亮度超过白点以后按平方根继续涨（颜色不变），免得整片烧白。原来的 8 位成像层原样保留为 `createLdrCinema`，不支持半浮点渲染目标或带 `?hdr=0` 时使用。
- 辉光仍然只是镜头效果：不改变光线落在哪里，不在阴影或视界上加发光层；诊断和外部观察不经过成像层。

**哪些是示意**：盘的半透明程度、絮状边界、色温的数值和幂次、细丝纹理、辉光强弱和胶片曲线，全部是按观感调的。真实的薄盘在这些波段是光学厚的；这里让它透光，是为了看起来像气体而不是一块板。

**验证**：`npm run check` 全量通过（数值检查不涉及这次改的上色）。在内置浏览器（Chrome 152，RTX 4070 Ti，1280×800）里手动看过开场、接近、掠过盘面、绕行、视界、视界内六个位置，`?hdr=0` 的降级画面，以及外部观察模式（画面和改之前一致，阴影中心是黑的，迎面一侧比另一侧亮）。暂停时两次取样的像素完全相同；同一进度下三个诊断取样点的分类颜色和线上版一致。

**没做的和没验的**：

- 浏览器检查后来用 Playwright（Chrome）全部跑过并通过：`check-schwarzschild-browser`、`check-flight-browser`、`check-cinema-browser`、`check-cinema-mobile`、`check-infall-browser`。
- 没有量帧率。半透明以后，穿过盘的光线要继续追踪，最坏的画面（盘铺满屏幕）会比原来慢；我估计在两倍以内，但没有数字。手机和核显没验。

### 可跨越视界的相机

以 r_s = c = 1 计算类时轨道：

```
(dr/dτ)² = E² − (1−1/r)(1+L²/r²), dr/dτ < 0
dφ/dτ = L/r²
```

用四阶积分制表，实际固有时间按同一轨道读取。另用独立二阶测地线方程核对半径和绕行角，步长减半核对收敛。

相机使用 Painlevé–Gullstrand 自由落体正交标架，避免视界处静止参考系失效：

```
ds² = −dT² + (dr + √(1/r)dT)² + r²dΩ²
γ = [E² + (1/r)(1+L²/r²)] / [E − √(1/r) uʳ]
βr = uʳ/γ + √(1/r), βt = L/(rγ)
```

过去指向光子的相机初值为 (−1,n)，经 Lorentz boost 转到此标架，得到径向坐标分量、角动量和 Killing 能量 e。沿 Binet 方程追踪；从内部出发不会因初始 r<1 直接终止。e≤0 不可能连接本模型的外部光源；光子球内若 b>b_c，则有效势阻挡它到达盘或无穷远，直接判暗。内部角度步长为 0.025/max(1,u)。

令接收频率为 1，真实光子角动量为 l_y，圆轨道盘面频移统一为 `g = √(1−1.5/r)/(e−Ωl_y)`，在静止模式严格退化到此前公式。恒星光频移为 1/e。静止阴影视直径不用于运动相机；右上改为坐标半径、累计绕行和船上时间。

### 径向释放实验

从 R 静止释放，E²=1−1/R：`r=R(1+cosη)/2`、`τ=R^(3/2)(η+sinη)/2`。船上时间有限地通过视界，演示停在 0.65 r_s。接收器独立固定在 30 r_s，以第一条释放信号到达为零点，接收时钟包含光程变化：`T=√(1−1/30)[t+r*(R)−r*(r)]`，`r*=r+ln(r−1)`。

信标 g 同时计引力与运动频移，并数值核对 `dT/dτ=1/g`。接收模式有限终点为 1.00001 r_s，不能声称外部收到穿越视界的信号。功率因子只计光子能量与到达率 `(g/g₀)²`，不是总光度。线性潮汐差 `Δa=2GM×20m/r³`；太阳 GM 使用 IAU 2015 B3 名义常数。

## 物理与数学约定

单位取史瓦西半径 r_s = 2GM/c² = 1，M = 1/2。黑洞不转、不带电。本节描述外部观察模式：观察者静止在 r0 = 1.6–60 r_s，始终在光子球外；运动相机见上方最新交接。

光子的轨道处于一个固定平面。令 u = 1/r、w = du/dφ：

```
u' = w
w' = (3/2) u² − u
w² + u² − u³ = 1/b²
```

φ 是光线在自身轨道平面内走过的角度，不是吸积盘绕轴的方位角。`orbit.js` 的 JS 参考和 GLSL 使用四阶 Runge–Kutta，角度步长 0.025，最多 1024 步。普通光线提前结束，预算不随观察距离或屏幕宽度改变。预算耗尽独立标记为 unresolved，测试不允许把它当成捕获。

本地视线单位向量 n 的径向、切向分量为 n_r、n_t，A0 = 1 − 1/r0。初值为：

```
u0 = 1/r0
w0 = −n_r √A0 / (r0 n_t)
b  = r0 n_t / √A0
```

径向光线单独处理。其他光线以径向单位矢量 e_r 和切向单位矢量 e_t 构建轨道平面，位置方向是 e_r cosφ + e_t sinφ。

- u ≥ 1：进入视界。
- u = 0：到无穷远；在最后一步内求根，直接用渐近方向采样星空。
- e_r.y cosφ + e_t.y sinφ = 0：赤道面交点。积分准确落到这个角度，再检查 3 ≤ r ≤ 12；不需要在盘旁边无限缩小步长。理想的共面光线没有离散交点，采用 10⁻⁶ 的方向容差处理 GPU 单精度插值误差。

解析临界瞄准距离 b_c = 3√3/2，静止观察者的阴影角半径满足 sinψ = b_c √A0 / r0。画面视场会随距离调整以便观察；右上读数始终是这个物理角度，不由 FOV 算出。

### 频移与盘的转动

盘轴取 +y；文献常写的 L_z 在此对应绕 +y 的角动量。反向追踪时：

```
lz = −(camera × n).y / √A0
Ω  = √(M/r³)
g  = √(1 − 3M/r) / (1 − Ω lz) / √A0
```

气体的坐标速度方向是 (Ωz, 0, −Ωx)。纹理使用其逆变换取样，与该转向一致。频移乘色温，积分辐射亮度乘 g⁴，再统一曝光映射。示意纹理的时间倍率 2.2 不参与频移计算。

### 独立的二维参考

`geodesic.js` 保留等价的笛卡尔加速度方程：

```
d²x/dλ² = −(3/2) h² x / r⁵
h = |x × dx/dλ|
```

用速度 Verlet 画二维光线，也给新积分器提供独立的盘面交点参考。弱场对比包含二阶项：α ≈ 2/b + (15π/16)/b²。累计偏折角不等同于绕中心完整转过的轨道角，页面已区分措辞。

## 物理结果与视觉示意的边界

| 按方程求得                   | 示意或理想化                                                       |
| ---------------------------- | ------------------------------------------------------------------ |
| 光线弯曲、解析阴影、高阶盘像 | 盘无限薄、光学厚，内沿 3 r_s、外沿 12 r_s                          |
| 静止观察者方向换算和频移 g   | 径向发光强度用 r⁻³(1 − √(r_in/r)) 模板，不是完整的相对论盘辐射模型 |
| 气体转向与频移符号一致       | 色温峰值约 5100 K、噪声纹理、演示时间倍率                          |
| 亮度的 g⁴ 变换               | 曝光映射、生成的背景星空                                           |

细亮弧是盘的高阶像，逐渐逼近临界光子环；不能把每一道可见亮弧都说成完整绕行一圈的光。没有克尔自旋、喷流、盘厚度或真实恒星图；新增探测器模式包含观测者运动的光行差。

## 操作与画质

- 拖动或方向键改视角；滚轮、双指或加减号改距离；Home 回默认。
- 默认 / 正侧面 / 俯视 / 贴近；吸积盘、频移、星空各自可开关。
- 暂停盘面后仍能转动视角、缩放。系统「减少动态效果」或 `?motion=0` 保持静态。
- 连续绘制慢时先降画布比例，最低 0.35，必要时减少普通区域采样；临界曲线附近保留加密采样。轨道步长不变。
- 静态画布比例至少为桌面 1、手机 0.85，DPR 上限 1.5。页面后台停止绘制。
