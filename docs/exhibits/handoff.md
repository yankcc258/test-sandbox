# 新奇想法网站：交接

2026-11-11 · 露娜写给**新对话里的露娜**和**特蕾莎**。Yank 把这个网站交给一个新对话专门做。这份文件是起点。

## Yank 要的是什么

原话的意思：

- 一个**拿来搞视觉冲击力**的独立网站。「就像是第二个研究科室，是专门弄这些莫名其妙的东西一样。」
- 里面是各种各样的东西：
  1. 知序里**之前觉得华而不实**的东西，可以放进去。
  2. **新做一些更有趣的内容**。他点名的第一件：史瓦西黑洞——「随时按照史瓦西的方程去模拟那个光线」。还有「各种各样很炫酷的东西都可以放在那儿」。
- 从知序过去的过渡（2026-11-06 说的）：不是简单跳转，而是「从实验室走到另一个科室的实验室」。
- 分工：**露娜做，特蕾莎审**。
- 知序主站以后只做朴素好用的界面，花哨的都放这边——所以这边可以放开做。

- **展品 02 · 洛希极限**（2026-11-11，猫猫，首版样稿，还没人审）：[`exhibits/roche/`](../../exhibits/roche/)，说明在 [roche.md](./roche.md)。碎石堆卫星的 N 体模拟，移近行星会被潮汐撕成环。同日按 Yank 的意见做了第二版（一分钟的影片、冰尘、辉光和影子），又按他的新想法改成第三版：**主页面是两颗虚构的行星站在彼此的洛希极限上，从观测舱看它们互相拉扯**（行星按等势面画成泪滴形，一百万粒碎屑是限制性三体问题里的试验粒子）；原来的碎石卫星实验挪到了 `exhibits/roche/moon/`。物理检查接进了 `check:exhibits`；两个浏览器检查脚本用 Playwright 跑过、通过；手机真机没验，连续动画的帧率没量，细节看说明里的「没做完的」。为了接入口，动了这几个共用文件：`index.html`、`docs/index.html`、`README.md`、`package.json`、`scripts/check-links.mjs`（各加一处，没有改原有内容）；样式是从 `blackhole.css` 拷出去改的，原文件没动。

## 规矩

- 沙盒（`test-sandbox`）**直接推 `main`**；正式站（`yank-study-lab`）不动，要动就照那边的规矩开分支提 PR。
- 每件展品：页面 + 一份 `docs/exhibits/` 下的说明（怎么算的、**哪些是真的哪些是示意**、请对方审什么）+ 能在 `npm run check` 里跑的检查（数对不对）+ 一个浏览器检查脚本（画面对不对）。
- 外部代码和素材先看许可证：MIT、Apache、OFL 可以用并保留许可文件；AGPL、GPL 和没写许可证的只学思路。
- 露娜这边只有软件渲染，没有显卡：画面对不对能确认，**帧率和手感要 Yank 或特蕾莎在真机上看**，交接里要写明。
- 和 Yank 说话用中文；别让他做选择题以外的技术决定。
