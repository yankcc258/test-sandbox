# 实验室 ⇄ 复习区：竖井下沉

2026-11-01 · 露娜。Yank 选了方向 A「竖井下沉」：复习区的脊柱竖着往下长，所以复习区被当成「实验室楼下」的空间。

## 区域安排

按 Yank 和特蕾莎的构想：

- **实验室**：学习区，不变。
- **复习区**：以后用这个沙盒的脊柱，替换正式站现在的观星台。
- **Yank 小屋**：观星台会搬到这里，做成单纯的观星平台，用来看星星、星象和天文事件。

这个过渡只管实验室和复习区这一对，观星台不用管。

## 看什么

- 打开 `?region=lab`：页面直接停在实验室。沙盒里的实验室只是一张占位截图，来自正式站 v2.43.2（`assets/lab/`），只有右上角的「前往区域」能点。
- 在实验室里选「复习区」，开始**下沉**（约 3.2 秒）：
  1. 地面亮起一道横缝。
  2. 截图切成 24 条横向薄片，用的是实验室缎带的「卡片」语言。薄片从横缝开始，往上下两边逐片翻成侧面，翻到一半时边缘反一下光；整个画面同时往上掠、放大，像镜头穿过横缝往下掉。
  3. 竖井：两侧的深度刻度往上掠过，左下角读数从 −000 走到 −128 M，中间脊髓的光渐渐亮起，显示「B1 · RECALL / 记忆巩固层」。
  4. 镜头先停在脊柱正上方往下看，再一边下降一边拉开，落到螺旋总览。同时脊髓信号从脊柱顶端一路流到当前屏幕那一节。
  5. 复习区的界面最后亮起，焦点落到「进入当前系统」。
- 在复习区选「实验室」，开始**上升**（约 2.7 秒）。如果正在内容页，会先退出。过程是：界面收起 → 信号沿脊髓往上爬 → 镜头升到脊柱正上方 → 进入竖井，刻度往下走 → 薄片从外侧开始逐片翻回 → 横缝闪一下合上。
- 如果脊柱模型还没载入完，下沉会停在竖井里，刻度继续慢慢往上掠，文字换成「正在载入脊柱…」，不会伪造进度。
- 关闭动效（`?motion=0` 或系统「减少动态效果」）时直接切换。
- 过渡期间、以及停在实验室时，复习区不响应滚轮、拖动、按键，也不响应点击定拍。

逐帧图在 `docs/lab-shaft/` 里：桌面下沉、桌面上升、手机下沉。

## 实现

| 文件                 | 内容                                                                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `recall-gateway.js`  | 时间线是纯函数 `frameAt(dir, t)`，另有区域菜单、薄片、竖井、进出焦点和测试钩子 `gate.pose(dir, t)`                                                                                     |
| `recall-gateway.css` | 薄片、横缝、竖井、区域菜单；复习区界面跟着 `--hud` 收起和亮起                                                                                                                          |
| `recall-spine.js`    | 改动很小：`scene.setShaft(k, sig)`（k＝1 镜头在脊柱正上方，k＝0 回到总览；sig 是脊髓信号）、`scene.sleep()`（停在实验室时不画复习区）、`scene.shaftTest()`（测试用）、过渡期间屏蔽输入 |
| `index.html`         | 原来右上角静态的「前往区域」标签换成真正的菜单，另外加了实验室占位层                                                                                                                   |
| `assets/lab/*.jpg`   | 正式站实验室截图（桌面 1440×900、手机 390×844 @2x），拍的时候藏起了正式站自己的区域菜单和希可的对话气泡                                                                                |

镜头路径是先升高、后收拢：脊柱顶端以下时，镜头始终在屏幕和椎骨的外侧，不会穿模。小屋在菜单里显示为「观星 · 天象 / 筹备中」，不能点。

## 以后接入正式站

- 正式站的实验室是 3D 的，缎带在 `src/room-scene.js` 里。「薄片翻开」那一段应该直接在实验室场景里做：缎带的卡片逐片转成侧面，镜头往下掉。沙盒里用截图切片，只是为了演示节奏。
- 后半段（竖井 → 镜头落到脊柱）可以原样搬过去。复习区的场景先以 `shaft = 1` 的姿态开始渲染，在竖井遮住的那段时间里加载模型，这一段已经有「没载入完就停住等」的逻辑。
- 正式站切区域靠的是 `src/regions.js` 的 `regionPick()`。到时候在它里面加「离开 → 到达」两段：实验室 → 复习区下沉，复习区 → 实验室上升；其他组合（比如去小屋）另外设计，或者先直接切换。
- 时间线已经拆成纯函数，以后可以给它配上 `lab-effects.js` 里的合成音效，比如翻片的轻响、竖井的低频。
