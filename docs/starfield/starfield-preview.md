# 星图探索 · v29

2026-11-03。基于沙盒 main `d43e0c0`，仅改 `test-sandbox`，未修改主站。最初“只保留内容”的预览按本次要求增加观察交互；下文历史说明保留用于追溯。

## 当前交互

- 在星图画布上左右拖动环视，滚轮或双指缩放；方向键、加减号和底部按钮也可操作。单指上下仍可滚动手机总览页面，资料内独立滚动。
- 点击星体实体（含土星环）、名称或底部八个入口，镜头靠近并打开星体档案。档案打开时轨道暂缓，关闭或 Escape 恢复进入前的方向与缩放；“恢复总览”回到初始视角。
- 基础资料与来源使用 NASA 官方事实页。实时部分沿用本地 Astronomy Engine 和原东京坐标，返回计算时刻、距地心距离、方位角、含标准折射的视高度、未来 48 小时内下一次升起与落下；月球另有照亮比例。地球显示观测原点，不计算地球对自己的升落。
- 观测信息按真实时间计算，每分钟更新；画面仍是第谷体系、非等比例、加速示意。地平线上方不等于满足天气及光照条件。
- 原今日天象和新的星体请求共用 Worker，以请求编号分发；快速切换或关闭后不显示过时回复。失败后保留基础资料并在后续请求重试，不在渲染线程执行天象搜索。
- 输入只更新相机目标，每帧最多绘制一次。减少动态效果／`?motion=0` 时停止自动运行，手动操作仍按需绘制。未连接学习功能、账号、正式数据或持久存储。

## 验证

- `npm run check`：含旧加载与跨东京午夜检查、新八星体观测、并发消息、输入取消、拖动不误点、多指释放及缩放边界。
- Chrome 实际检查桌面实体点击、拖动、滚轮／按钮缩放、星体切换；390 × 844 与 320 × 568 手机档案、独立滚动、无横向溢出。静止模式保留手动操作，关闭后准确恢复总览的方向与缩放。
- 双指手势的指针状态由自动检查覆盖；未以实体触屏设备验收手感。

## 保留的内容

- 原观星台的深墨蓝／银白／淡金、银河光雾与星点、NASA 行星纹理、地球昼夜面、太阳光源、土星环。

- 东京今日天象、后续天象及原牛顿／开普勒文字。天象由本地 astronomy-engine 计算；流星雨日期沿用原先的近似值并标注「约」。
- 桌面星空全景，窄屏下方接续天象与文字。系统减少动态效果或 `?motion=0` 时保持静止，纹理载入后仍会补绘。

## 移除的功能

页面没有按钮、链接、学习入口、复习计数、设置面板、音乐控制、区域跳转、星体点击、拖动或缩放。没有账号、接口请求、持久存储及学习数据；不载入正式站路由、复习控制器或其他业务脚本。

## 来源与维护

图形和天文计算取自正式仓库 `adc6e21` 同树的本地 `fd28b7e`：`orbit-models.js`、`orbit-space.js`、`orbit-sky.js`，在沙盒内独立运行。仅从正式仓库读取与复制所需文件，没有修改它。

`starfield.js` 只管理只读天象内容、相机、轨道和文字避让。原模型贴图路径已改成相对模块路径，适配 GitHub Pages 的 `/test-sandbox/` 前缀。纹理随预览托管，不依赖 CDN。

- [NASA 图像来源](../../preview/starfield/NASA-imagery.md)
- [astronomy-engine MIT 许可](../../preview/starfield/vendor/astronomy/LICENSE)
- Three.js 和 Inter 沿用沙盒本地文件及其许可证。

后台页面暂停绘制，返回后接着运行，不追赶离开期间的轨道时间；无 WebGL 时保留天象与文字，并提示立体星图不可用。
