# 研究员工作台范本 · v19

2026-11-02 · v18 基于 238a152 搭建，v19 基于 f3b52b0 精修。工作仅位于 test-sandbox，未改正式仓库。

## v19 材质、光影与物件精修

按用户要求保留桌前构图与物件位置，本轮没有做跨区域转场。仍沿用已确认的克制科研机构方向：石墨外壳、象牙白曲面、钛金属支撑与深色玻璃。对照仓库内实验室与脊柱区的实景截图，让功能物件有相同的材质层次。

- 增加原创、可重复生成的细微表面纹理：金属拉丝、石墨颗粒、纸张纤维与织物起伏。材料共享小尺寸贴图，不增加外部下载。
- 重做设备的圆角、玻璃覆层与边缘，平板补上密封缝、镜头、扬声孔、支架和供电线。试样柜增加脚垫、底座、玻璃侧面、紧固件和标牌。
- 莫比乌斯试样从双面薄片改为有真实厚度、连续法线的闭合曲面，补上钛金属夹持件。自阴影帮助读出折转；玻璃不再投下不透明的遮挡阴影。
- 台灯增加双臂、铰链、线缆与散热槽；杯子改为有内壁和杯沿的旋转体，增加液面和杯垫；手记采用轻微卷曲的纸页，补上纸夹与笔尖、握环。资料夹补封面与书脊，休息位补软垫与缝线。
- 使用一次烘焙的原创柔光反射环境，结合侧向主光、冷色轮廓光、桌面接触阴影和台灯聚光。静止时仍按需绘制；固定灯位的阴影贴图在镜头移动时复用，WebGL 恢复时重建。
- 窗框增加凹槽、密封边和窗台层次；窗外用柔和云层与远近建筑取代原来的硬线条。东京时段逻辑保持不变。

## 最新设计约束

- 工作台是实验室、脊柱区之外的第三个区域。共用深石墨、象牙白、钛金属、深色玻璃、细线编号，以及轻微变化的东京时段环境光。
- 用户认可克制的科研机构方向。生命、材料、人工智能与天空通过研究对象、终端内容和窗外表达；不要把整间房画成骨架和生物膜。
- 早期复古未来 / 构成主义分支、满屋骨骼方案已经放弃。露娜的早期 layout.svg 保留作过程记录，不再是固定布局约束。
- 当前先做可浏览、可操作的三维范本。未来要支持 1⇄2、1⇄3、2⇄3 连续镜头；本轮仅把三处入口连通，没有把页面跳转包装成已完成的区域动画。

工作台包含原创程序几何的桌面、薄边平板、台灯、杯子、莫比乌斯带材料试样、手记、窗台纸飞机和希可的空置休息位。希可本体及正式工具未接入。

1. 拖动空白处小幅观察，松手回正；按钮和物件均可打开内容。
2. 平板推近并展开同色玻璃终端，支持今日概览、25 分钟专注计时和当前页面便笺。
3. 计时按实际经过时间计算，可暂停续计，收起终端后仍计时。便笺在关闭面板、切换页签后保留，刷新清空。两者都不写入学习成果。
4. 研究手记、试样说明采用原创示例内容。材料模型没有真实实验测量数据。
5. 纸飞机打开天空说明，可进入既有星空内容预览，再返回工作台。没有提前实现或替代规划中的飞行器演变动画。
6. 台灯可独立开关。右下角可预览晨光、黄昏、深夜；默认自动读取 Asia/Tokyo，6:00 / 16:00 / 19:00 后用半小时缓慢交接。
7. 动效关闭或系统减少动态效果时直接切到镜头位置，界面不播放展开动画。静止时不持续绘制，隐藏页面暂停绘制；没有 WebGL 仍能通过底部入口使用终端、手记。

预览参数：`?motion=0` 关闭动效，`?light=day|dusk|night` 检查时段，`?view=fallback` 检查无 WebGL 回退。参数仅属于此范本。

## 沙盒整理

- 根 index.html 现在是轻量目录，不启动 WebGL。当前工作台突出展示；复习、竖井、星空各有明确状态和入口。
- 原根页面移动为 recall.html，原脚本和资源位置不动，避免破坏已确认的脊柱体验。
- 旧的根路径参数链接自动转到 recall.html，保留查询参数与 hash；v13–v17、i、workbench、region、motion 继续可用。裸根地址展示目录。
- preview/index.html 只做历史与模型档案，round-0、round-1 和 organic-spine 的路径不改。
- README 改为简明当前说明；原来的完整说明保存在 docs/history/review-sandbox-v17.md，历史设计稿标记为历史。
- 星空原始地址保持内容预览；仅从目录或工作台进入时增加一个返回来源的链接。
- 复习区“前往区域”的第三项打开新工作台。离开复习页面仍会清空其内存示例状态，和原沙盒的刷新边界一致。
