## 看这一条路径

打开 `?i=1&v=16` → 进入当前系统 → 开始本轮 → 翻面、自评 → 完成本轮 → 返回脊柱。

- **进入**：把场景玻璃屏的四角投影到页面，用透视变换展开到固定阅读位置。器材边框、系统编号和材质延续；本链路关闭中心白光。没有增加启动动画。
- **准备**：沿用大脑结构图，只突出本轮 8 词和开始入口。说明收进可展开区域。浏览准备页不算开始练习。
- **练习**：单词和控制区有固定空间，翻面只揭示释义；评分后继续下一张。烟色玻璃、细钛金属边缘、象牙白文字和低亮冷色贯穿整个流程。
- **报告**：仍在原来的屏幕中展示实际唯一完成数及首次回想分布。主动返回后屏幕收回原位，沿用生命体连接反馈。
- **中断**：返回保留卡片、队列和翻面状态。今日复习与背单词共享这一组示例。

## 流畅度与输入

进入约 1 秒，返回约 0.7 秒；使用真实经过时间推进，物理更新的步长限制不再拉长镜头动画。快速取消或重新进入接管当前进度，不排队。阅读期间停止场景 RAF；只有返回、尺寸变化、模型就绪等需要时重绘。没有截图读回、额外的 WebGL 场景或大面积背景模糊。

关闭动效 / 系统减少动画时直接到位；没有 WebGL 时仍可通过列表进入全部示例流程。焦点进入操作屏，Tab 在屏内循环，ESC 返回；空格翻面、1/2/3 自评，长按不连续评分。短屏内部可滚动，返回按钮始终保留在底边。

## 数据边界

只有 8 个示例单词，数据保存在当前页面内存；刷新或 ABOUT 重置后清空。忘了隔三张再试，首次模糊回队尾，回队不重复累计完成数；按钮描述的是本轮行为，没有假装连接正式调度器。练习用时从主动开始计算，返回或页面转到后台期间暂停计时。其余笔记、错题、测验仍为内容预览。
