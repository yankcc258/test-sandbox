## 一、三个区域之间的竖井

知序像一栋楼：**2F 研究员工作台**，**1F 实验室**，**B1 脊柱复习区**。在区域之间移动，都坐同一条竖井：

1. **离开**：当前画面切成横向薄片，从中间那道缝开始逐片翻成侧面。实验室的薄片是缎带上的卡片；工作台的薄片是窗边的百叶。
2. **在竖井里移动**：两侧的深度刻度掠过，左下读数显示高度（2F 是 +036 M，1F 是 ±000 M，B1 是 −128 M）。右侧的楼层表上有一个黄绿色小方块，跟着当前高度移动，经过的楼层会亮一下。
3. **到达**：
   - 到工作台：此刻桌前的画面切成百叶，从外往缝翻回来。
   - 到复习区：接原来「下沉」的后半段，镜头从脊柱正上方落回螺旋。
   - 到实验室：接原来「上升」的结尾，截图薄片合上。

| 路线                     | 怎么走                                                                           |
| ------------------------ | -------------------------------------------------------------------------------- |
| 实验室 ⇄ 复习区          | 同一页，原来的竖井动画不变；楼层表在 1F 和 B1 之间走                             |
| 实验室 / 复习区 → 工作台 | 在这一页播完「离开」，竖井完全不透明的那一刻换页；工作台接着播「上行」和「到达」 |
| 工作台 → 实验室 / 复习区 | 工作台百叶翻开、竖井盖满，然后换页；复习页接着播「下行」，再接原来的到达动画     |

**换页时怎么交接**：`sessionStorage` 里的 `zhixu-passage` 记下从哪来、到哪去。这条记录只在 8 秒内、而且目的地就是本页时才认，读一次就删，所以刷新不会重播。新页面的 `<head>` 里有一小段脚本，先用井壁色盖住页面，等竖井挂上再揭开，不会闪出半截内容。

**工作台的模型还没准备好时**：竖井会停在快到站的位置等，刻度继续慢慢掠过，不伪造进度。

**关闭动效或系统减少动画时**：直接跳转。

## 二、纸飞机 → 星空（星空的载入画面）

点窗台上的纸飞机（或「窗外与天空」）。镜头先转向窗户，纸飞机从窗台的位置起飞，飞到画面中上方，然后同一条航线一路换代：

| 阶段         | 年代  | 高度   |
| ------------ | ----- | ------ |
| 纸飞机       | 窗台  | 1 M    |
| 飞行者一号   | 1903  | 30 M   |
| 双螺旋桨客机 | 1930s | 3 KM   |
| 喷气客机     | 1950s | 11 KM  |
| 航天飞机     | 1981  | 100 KM |
| 运载火箭     | 今天  | 400 KM |

- **天空**：从窗外当时的颜色（跟着东京时段）一路暗成太空。
- **云**：越飞越快地落到下面，穿出云层后消失。
- **太空**：高空以上星星慢慢亮起，地球的边缘出现。火箭越飞越远，变成一颗星，屏幕中间浮出齐奥尔科夫斯基的那句话：「地球是人类的摇篮，但人不能永远生活在摇篮里。」
- **进入星空**：全程约 10 秒，右上角可以跳过（ESC），跳过后会直接到那句话。之后进入星空页面（观星台内容预览）。星空页先接住这一帧（太空、星星、那句话），等星空载入后再淡出，所以这段飞行本身就是星空的载入画面。
- **画法**：所有飞行器都是露娜画的俯视剪影（机头朝上，用 Canvas 画），火箭用侧视，没有用任何航空公司或机构的涂装和标志。

## 三、平板开机

点平板：

1. 镜头推近（沿用 Codex 的 `scene.focus`）。
2. 屏幕在它真实的四个角里亮起：中间一道横向的光拉开，屏幕点亮，「知序 · 个人终端」和进度条出现。
3. 亮着的屏幕从平板的轮廓展开成个人终端。

关闭时反过来：终端收回到平板屏幕里（镜头同时退回座位，屏幕跟着移动），然后熄屏。

开机画面放在顶层（popover），能盖在终端对话框上面，但只负责画面，不接收输入。关闭动效时直接打开。

## v28 纸飞机与星图加载优化

2026-11-03，基于露娜 v27（`21d0fc9`），只更新沙盒。十代飞行器、时间线、文案、星图内容和工作台布局保持原样。

- 云团在起飞时预绘制并复用，云层帧不再重复创建径向渐变。移动画布限制为约 200 万像素，文字仍用原生分辨率的 DOM；读数每 0.1 秒更新，阶段文字只在换代时更新。
- 飞行期间以两路低优先级请求预取星图脚本和贴图，不运行第二个 WebGL 场景。预取失败仍可正常导航加载。
- 日出日落、月相与未来天象搜索改为 Worker 计算。页面先构建场景，贴图加载后分批上传，再预编译材质；缺少纹理继续使用现有程序材质。
- 离开时暂存飞行画布的最后一帧，只包含本页生成的天空。到达页沿用这张图和同位置引言，等星图首帧就绪才淡出，避免重新随机生成星点造成跳变。脚本失败有超时退出，关闭动效直接揭开。
- 行星标签的尺寸在布局变化时缓存，避免每轮定位交替读取尺寸和写样式。希可在飞行覆盖层后暂停逐帧工作，东京时钟格式器复用；v27 的活动、睡眠与记仇本行为保留。
- 页面隐藏时暂停飞行，恢复后续播；浏览器后退恢复工作台时清除旧覆盖层，可以再次起飞。

验证：`npm run check:starfield` 对实际 Worker 做结构化克隆往返，结果与原计算在东京午夜前后完全一致；同时覆盖预取失败、并发上限、像素预算、首帧就绪／超时／关闭动效的揭幕逻辑。`npm run check` 一并运行原有检查。

浏览器对同一桌面云层帧计数：v27 为 72 次径向渐变，新版为 0 次（18 次已缓存云图绘制）；移动画布从 2559×1201 限至 2063×968。此处是绘制操作计数，不是帧率基准，未据此声称真实手机稳定帧率。

Chrome 实测桌面完整飞行、跳过、浏览器后退后再次进入，窄屏完整飞行与关闭动效直达星图。到达后首帧状态为就绪、覆盖层已移除、天象正常，窄屏无横向溢出；控制台未见错误或警告。未在真实手机硬件测量帧率。
