## 新的空间分工

**脊柱总览**继续承担系统选择、状态和进入动作。点击后，同一块玻璃展开成接近全屏的工作台，不更换场景材质，不增加白光，不重建第二个 WebGL 场景。桌面最大宽 1560，窄屏留 8 像素边缘；内部布局按内容而不是按屏幕上的物理玻璃尺寸排版。

**浏览工作台**由左侧栏目、中央正文、右侧资料组成。栏目与返回位置固定，主内容自然纵向滚动；词表分页显示 20 条，宽表格／代码块仅在自身区域横向滚动。正文最大阅读宽度 760，不把长句拉满整个窗口。1200 像素以下收起辅助栏；笔记资料在正文下方折叠保留。

**专注练习**收起右侧资料，只留题目、进度与操作。单词、翻面释义、四档评价和完成报告共享同一外框。手机四档评价排成 2 × 2，设置和词库通过顶部栏目打开；输入框输入不触发评分快捷键。

## 本轮可操作的范围

- 背单词：概览、新词预览、词库浏览、偏好排版、真实可操作的八词回合、四档评价与完成报告。
- 词库：主站 `vocab-more.js` 的知序自编化学术语 100 条、大学与理科日语 100 条，以及原八词样例。后者日语词库在主站已隐藏，这里仅用其已有内容检验中日文容量，不代表恢复正式入口。搜索、分页、展开例句可用，不含学习进度。
- 练习：沿用沙盒队列，增加「很熟」立即完成；仍没有正式 FSRS 下次复习时间。概览的已巩固数量只来自实际示例练习；浏览词库和长文不计成果。离开专注页时暂停计时与生命状态，返回时保留队列、翻面与进度。
- 偏好：本页表单状态可调整和保留，明确标为参数布局预览；当前练习固定八词。发音设备选择未接入，显示禁用占位。
- 笔记：原创六节排版样例，含长段落、公式、宽表格、代码块与可展开资料；无导入、保存或出题，表内数值不代表实验结果。目录跳转、附页、返回再进入的阅读位置可用。
- 其余入口沿用已有内容占位，仅采用扩展外框；尚未声称完成七个系统的真实业务接入。

## 主站接入的具体边界

| 系统     | 工作台承载方式                                         | 必须沿用的主站行为                                                             |
| -------- | ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| 今日复习 | 单词／笔记／测验／错题分组队列；摘要与详细列表分开     | 真正的到期计数、未知／加载／错误状态                                           |
| 背单词   | 词库选择与概览、独立新词预览、专注卡片、词表管理、偏好 | `vocabRun`、四档 FSRS、复习间隔、服务器持久化、朗读、自建卡片与 Markdown／公式 |
| 笔记复习 | 文件夹列表 → 长文阅读；目录和辅助资料分栏              | Obsidian 导入、筛选、编辑、标签、引用、反向链接、笔记检查与出题                |
| 错题回访 | 可筛选列表 → 单题复访；答案与解析按阶段呈现            | 历史答案、已巩固归档、重练与课程链接                                           |
| 综合测验 | 题号侧栏、中央题干与作答、提交后的反馈及来源           | 草稿恢复、提交幂等、评分、引用、真实／示例区分                                 |
| 复习记录 | 日期分组与筛选；按需展开单次记录                       | 真实去重计数、词条／笔记／测验来源                                             |
| 复习设置 | 按学习节律、笔记出题与声音分类的表单                   | 原校验、保存、错误与同步状态                                                   |

接入时应拆开提交：先接工作台外壳及连续转场，再按模块重排原组件，最后接真实完成反馈。`recall-terminal.js` 的几何转换、外框样式和状态衔接可以迁移；本轮示例队列、演示词库、示例正文与参数表单不能替换主站业务。原电子环绕开场保持不变，不引入已删除的沙盒开场。主站仍开分支与 PR，依其仓库要求跑完整测试及格式检查，由用户合并。
