# 沙盒体验第一轮：开场、切换、复习反馈与生命状态

2026-11-01。仅修改 `test-sandbox`，没有接入知序正式站；保留有机脊柱第三稿及全部模型资产、材质配色。

## 看什么

1. 首次进入：原创轨道标识聚合 → 知序身份 → 真实空间唤醒。资源就绪时约 3 秒；模型仍在加载时停在连接阶段，不虚构百分比。镜头已在同一空间，光线和脊髓信号接续到总览。
2. 换系统：沿原本连续的螺旋路径移动，脊髓传递一次信号，目标连接微亮，主光在途中轻压再恢复；不是黑场切页。快速输入替换当前交接，不排队。
3. 进入 / 返回：沿用并接好神经连接、镜头推近、内容淡入；返回时保持同一位置。输入取消不会误触进入。
4. 生命状态：静息待命 → 巩固中 → 已暂停 / 本轮连接已稳定。状态、进度条、玻璃屏计数、今日复习、复习记录共用一份当前页面状态。
5. 完成：摘要显示本轮巩固数量、首次回想分布；由用户选择返回，避免还没读完就自动跳走。返回后信号从连接送回脊柱，留下低亮稳定连接和短暂文字反馈。

## 如何测试

- 打开根页面，或 `?i=1` 直接到大脑 / 背单词；左侧“进入当前系统”也能进入。
- 只有 **8 个不同的示例单词**可实际练习。翻面后按 1 / 2 / 3，或点击按钮。遗忘、模糊的词会按原规则再次出现，不重复计入完成数量。
- 做到一半按 ESC，换到其他系统，再从背单词或今日复习进入：卡片、队列、翻面状态和进度均保留。
- 完成全部 8 个词后返回，观察稳定连接；再进入“复习记录”核对本轮成果。
- 今日复习从 25 降到 17：剩下的 9 笔记、6 错题、2 测验仍是内容预览，不会被假装完成。复习记录已改为本轮真实示例结果，不再用固定连续天数表示成果。
- ABOUT → **重播开场**，或 **重置本轮示例**。关闭动效 / 系统偏好减少动画时不播放开场或运动过渡，功能及结果照常可用。
- 所有练习进度和记录只保存在**当前页面内存**；刷新页面或重置后清空。开场“已看过”使用当前标签页的 sessionStorage，与练习数据分离。

## 实现边界

- `recall-opening.js` 管理加载、跳过、焦点恢复、后台暂停和会话播放策略。
- `recall-life.js` 管理唯一完成计数和单次完成记录；点击节拍、心率和彩蛋不参与学习进度计算。切换信号可中断，关闭动效即清理。
- `recall-experience.css` 是本轮增加的界面样式；现有模型不重建。脊髓复用已沿椎孔拟合的几何体，只新增一个短时信号绘制层。
- 保留露娜修正后的脊髓位置、神经起点、手机内容层级、现有音乐和点击定拍。
- 开场图形、代码与动画全部原创，仅借鉴“身份建立后进入同一空间”的叙事顺序；没有复制参考站代码、字体、音频或图像。
- 本轮“换场景”指沙盒现有七个系统之间，以及总览与内容之间的切换。正式站实验室、小屋、观星台的跨区域接入尚未进行。

## 验证

- `npm run check:experience`：真实卡片评分循环、遗忘与模糊回队、暂停恢复、唯一计数、单次完成、重置、快速切换覆盖、关闭动效；开场资源等待、低帧率时序、跳过、会话策略、后台暂停、减少动画与帧清理。
- `npm run check:pulse`：保留原有节拍、静息恢复、答题锁定、过载恢复与点击过滤验证。
- Chrome 实际操作：桌面完成 8 词、部分完成后切换再继续、查看记录、关闭动效进入返回、重播及跳过；窄屏评分和重置，无水平溢出。
