## 三、复习脊柱现在是什么样

- **脊柱**：Codex 做的有机脊柱第三稿（`assets/models/organic-spine-scene-v3.glb`，约 2.56 MiB、43 万三角形，`models/sculpted-spine.js` 加载）。象牙白楔形椎体 + 钛骨弓 + 开槽支撑片和紧固件，73 节沿 S 形曲线排列。「脊髓」沿每节椎孔中心（椎骨局部 `(0, 0, -0.19)`）穿过。
- **DNA**：左右两条光点双螺旋，一近一远，以 0.45 倍速度跟随镜头，有视差和遮挡。
- **屏幕**：七块深色磨砂玻璃（透射材质），从左往右沿螺旋下沉；边缘光随主光方向和掠射角变化；待机时各自极慢摆动；悬停时摆正放大、扫过一道光。
- **记忆生命体 ZH-01**（Codex 最新加的）：七个入口各对应一个身体系统（今日复习＝心脏、背单词＝大脑、笔记＝神经丛……），屏幕上有原创细线结构图，左侧显示标本说明。见 `docs/living-specimen.md`、`recall-specimen.js`。
- **心跳**：按有效点击的间隔定拍（`recall-pulse-input.js`），停下后恢复 64 BPM；三秒内至少九次有效点击且到 152 BPM 才触发「记忆过载」彩蛋。进入内容、拖动、右键、音乐和关于页都不计入。
- **镜头**：滚轮和拖动连续控制进度，停手 0.16 秒后平缓吸附；拖动带惯性；列表和方向键准确跳转；两个入口之间镜头稍微领先、退后、视线收向脊柱。
- **进入**：默认「神经」过渡（椎骨光环 + 两条神经长到屏幕上角 + 光脉冲 + 镜头推近），`TRANSITIONS` 注册表留给七个入口以后各做一套。进入后内容是**独立版面**（桌面居中玻璃面板、手机全屏可滚动）。
- **背单词示例**（`recall-vocab.js`）：8 张卡，空格翻面，1 忘了 / 2 模糊 / 3 记得，重排队列，结束统计，完成后背单词和今日复习数字同步减少。
- **胶囊导航**（`recall-dock.js`）：ARCHIVE 回到顶部、中间波形是音乐开关（Web Audio 实时合成的三首氛围长音，没有音频文件）、ABOUT 关于页（经纬线球 + `LEARN → RECALL → BEYOND` + 「天空并非极限」）。

## 五、工作约定

- **版本号**：改了任何被 `index.html` 或模块导入的 JS/CSS，都要把 `?v=N` 一起加一（`index.html`、`recall-spine.js`、`models/spine.js` 里都有），否则浏览器会把新页面和旧脚本混用，按钮就会「没反应」（这个坑踩过一次）。
- **格式**：仓库有 `.prettierrc`（单引号、行宽 100）。用 `npx --yes prettier@3 --write <文件>`。
- **许可**：版式参考的 `reverieach/rhine-lab-art` 的场景、着色器、模型、贴图和音乐**没有开源许可**，CG 和标志属于鹰角网络。只能参考思路，不能复制任何文件，也不用莱茵生命的名字和标志。新加图片、模型、音乐都先确认来源和授权。
- **和 Codex 分工**：Codex 也在这个仓库直接推送。开工前先 `git pull`，看最新提交和 `docs/` 里它写的说明，改它的文件时改动尽量小，并在说明里写清楚。
- **截图检查**：每次改完用 Chromium 截桌面 1440×900 和手机 390×844，确认没有脚本错误、按钮都在面板里、没有横向溢出。

## 六、冒烟测试

`scripts/smoke/` 里是露娜上个窗口用的 Playwright 脚本（环境自带 Playwright，不用安装）。先在仓库根目录起服务：

```sh
python3 -m http.server 8811 --bind 127.0.0.1
```

然后按需要运行：

| 脚本                                        | 检查什么                                                                                 |
| ------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `node scripts/smoke/flow.cjs d`（或 `m`）   | 进入背单词、翻面、整组评分、统计、返回；按钮是否溢出；内容区点击不改变心率               |
| `node scripts/smoke/scroll.cjs`             | 慢滚、停手吸附、快滚、拖动反向、松手吸附、列表跳转、方向键                               |
| `node scripts/smoke/dock.cjs`               | 音乐开关和波形、切曲目、ARCHIVE、关于页开关、ESC                                         |
| `node scripts/smoke/btn.cjs`                | 按真实坐标点击 / 手机触控各按钮，以及模拟 3D 场景出错时按钮仍可用                        |
| `node scripts/smoke/cmp.cjs <前缀>`         | 拍四张对比图：桌面停在背单词、两屏之间、综合测验，手机停在背单词                         |
| `node scripts/smoke/gate.cjs d`（或 `m`）   | 实验室 ⇄ 复习区：真实点击来回切换、焦点、按键屏蔽、内容页先退出、关闭动效直接切换        |
| `node scripts/smoke/gate-frames.cjs d down` | 竖井过渡逐帧截图（`d`/`m`，`down`/`up`），用 `zhixuSpine.gate.pose(dir, t)` 停在固定时刻 |

软件渲染只有约 1 帧每秒：动效开启时不要直接截图，用页面上的测试钩子（`window.zhixuSpine.scene.settle / run / hoverTest / enterTest / simulate`）按固定步长推进后再截。
