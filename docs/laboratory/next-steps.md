## 后续顺序（本轮不提前实施）

1. **补齐观察对象**：剩余六章非有机内容——浓度、波函数、自由能、原电池、电子排布、受力与功。每次选一章，按核心概念补必要积木，加入原题核对，再做视觉检查。
2. **有机三个章节先做小样**：成键/杂化/官能团、电子效应/酸碱/共轭、SN2/SN1。先确定如何表达结构和反应过程，再决定球形原子、键、轨道和反应路径的实现；不未经核对自动生成科学模型。
3. **整体学习体验验收**：长正文、章节切换、观察区占用、键盘/手机操作、快速连续输入、关闭动效、低性能设备。此次响应式浏览器测试不等同于实体手机帧率验证。
4. **正式站接入准备**：另行安排后才开始。核对届时最新正式站，保留课程 ID、原题顺序、检索、先修、访问记录、进度与原电子环绕开场；列清适配范围、回退方式和测试结果，再提 PR。
5. **第四层 Agent 区**：继续留在方向讨论阶段，先明确与工作台的分工、可执行任务、过程呈现及操作确认，再定美术和模板。
