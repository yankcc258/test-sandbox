## 历史：v38（2026-11-04 JST）

特蕾莎按 Yank 本轮要求补波函数与自由能两章。开工和发布前均同步远端；起点 `902165e`，露娜此前的目录搬迁、环居中和配方基础全部保留。只改沙盒，主站未动。

入口：[波函数](../../laboratory/?v=38&chapter=quantum-wave) · [自由能](../../laboratory/?v=38&chapter=physical-gibbs) · [五份配方集中预览](../../laboratory/specimens/?v=38#quantum-wave)。

- **波函数**：沿原课 L=1 nm、n=1–4，显示 √Lψ=√2 sin(nπu) 和 Lρ=2sin²(nπu)。两根滑杆为 n、积分上限 b。象牙白密度、冷色正负振幅、黄绿区间薄片与内部节点标记共用原材质；b=0 没有概率薄片，b=1 覆盖整箱。薄片中点近似，读数用解析积分 `P(b)=b−sin(2nπb)/(2nπ)`，不会把密度高度当作概率。
- **自由能**：原课没有专属模型，本轮按其理想 A⇌B 例题补充。固定 298 K、总量 1 mol；参数为 B 的摩尔分数 y 与平衡常数 K（1–10）。相对纯 A 的体系曲线 `G=RT[y ln y+(1−y)ln(1−y)−y ln K]/1000`，端点采用 `0 ln 0=0` 的极限。当前点为黄绿环，平衡点为冷色环；箭头只指降低 G 的方向，不代表速率。最低点 y=K/(1+K)，当前反应自由能 `ΔᵣG=RT ln(Q/K)` 与标准值分别显示。K 控件比较同温度不同标准自由能的理想体系，改变组成不会改变 K。
- 固定坐标范围，不跟随当前点自动缩放。自由能当前组成避开纯物质端点（0.01–0.99），曲线本身绘至 0、1；不会在端点直接计算无穷大的反应自由能。
- **共用接口（给露娜）**：仅为薄片添加可选 `baseline`（默认原图下界）、`until`（截断最后一片，空区间保留隐藏槽位）、`color`，为竖线添加可选 `from`。旧配方不需要迁移；两章直接加入 `specimen-recipes.js`，集中预览自动收录。没有改原课程快照、题目、判题、正式数据或独立流星小样。实验室模块缓存更新为 `v38`。
- 原有五个数学模型加五个配方模型，现有 10 章专属观察；剩下 7 章仍为中性档案，不假装已做完。

### 体验流程

1. 在总览点按数学薄片、旁边的“数学 · 聚焦”标签或“聚焦数学”按钮，镜头进入局部。

### 几何示意与本章真实算例

观察曲面使用 `y = (x² − z²) / 2`，其中 x、z 为水平坐标，y 为高度。

| 模式     | 可观察的内容                                                    |
| -------- | --------------------------------------------------------------- |
| 曲面     | 马鞍曲面及参数网格；可旋转查看整体，滑杆暂不启用。              |
| 切平面   | 选取 `(a, f(a,b), b)` 处的切平面，固定 `b = 0.30`，滑杆调整 a。 |
| 水平截面 | 水平面 `y = c` 与曲面的交线；滑杆调整 `c ∈ [-0.50, 0.50]`。     |

上方马鞍只用于观察局部曲面、切平面和截面的关系，**不是**本章 `f(x,y) = x²y` 的三维图形。右侧另设独立数值算例：从 `(2,3)` 出发，调整 dx、dy，对比一阶估计 `df = 12dx + 4dy`、精确变化 `Δf = (2+dx)²(3+dy) − 12` 及二者之差。“步长减半”同时缩小 dx 和 dy；这些数值操作不会改变马鞍模型，也不会代填练习答案。

原例 `dx = 0.1`、`dy = −0.2` 对应 `df = 0.4`、`Δf = 0.348`，估计比精确值高 `0.052`。正文保留原文，并补一条阅读注：原文“原点处”在此指本例起始点 `(2,3)`，并非坐标原点。

v30 / v31 的“局部坐标与曲面”“切平面：局部的线性近似”“水平截面：把曲面切开”是早期原创示例稿，不再作为当前课程入口。

### 布局与降级

总览和观察阶段保留螺旋与曲面为主体。进入课程后，桌面使用左侧章节目录、中间宽正文、右侧观察区，正文与侧栏分别滚动；观察区可收起以放宽正文。较窄桌面将目录改为横排。手机以正文为主，观察区默认折叠，主动展开后位于正文前方，页面自然滚动。三维区域迁移同一个 canvas，不另建一套模型。界面沿用实验室细线与无大玻璃框的排版。

顶部显示东京时间，并按东京时段轻微调整环境光。动效按钮、系统“减少动态效果”及 `?motion=0` 均可停止自动运动和阶段缓动，手动选择仍可使用。无 WebGL 或 `?view=fallback` 时提示立体模型不可用，仍保留课程正文、原题与数值算例。

本地页面示例：

- `laboratory/?v=35`
- `laboratory/?v=35&motion=0`
- `laboratory/?v=35&view=fallback`
