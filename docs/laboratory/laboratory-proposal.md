## 一、Yank 这次定下的方向

1. 大螺旋展开后不再只放一个马鞍。右侧观察区原来的默认模型，改成螺旋展开出来的丝带。
2. 丝带要像**流体或流星**一样流动，不再是现在那三条固定的带子。Yank 原话说现在展开后的三条丝带「不是很好看」。
3. **点进一章**：流星飞到右边，像一段动画那样**组装成这一章的互动模型**。组装完就停住，可以拖动、调参数查看。例如定积分会组装成「曲线下面的一排象牙白薄片」。
4. **换下一章**：模型散回丝带，再重新排成下一章的模型。例如从定积分换到「复数与概率归一化」，就重排成复平面。
5. 化学的三个方向也要用这套。物理化学可以直接沿用；**有机和无机的互动要重新设计**。
6. **螺旋的背景要换**。

## 二、和正式站已有内容怎么对上

正式站已经有六个学科、三个有课，一共 17 个单元，还有「课程档案阵列」（就是那个像文件夹一样的界面：抽出档案、详情、检索、访问记录）。新空间要把它们都装进来，不丢东西。

| 正式站现有的（`course-archive.js`、`curriculum.js`、`room.js`）  | 在大螺旋里变成什么                                                                          |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 6 个学科（物理、数学、化学有课；计算机、生命、地球与空间规划中） | 螺旋沿长度分成 6 段，一段一个学科。没课的段薄片收着、暗一些，点开只显示规划方向             |
| 每个学科的方向（化学是物理化学、有机、无机三个）                 | 展开后的一股丝带流 = 一个方向                                                               |
| 单元（档案卡）                                                   | 丝带流上的一组薄片，一片对应一道题（见第三节）。悬停章节名时这一组亮起                      |
| 抽出档案 → 详情（概述 / 进度 / 访问记录 / 先修）→ 开始学习       | 选中的那一段薄片化作流星飞到右边组装标本；旁边显示详情；「开始学习」进入 v32 的宽正文工作区 |
| ⌕ 内部档案检索、按科目筛选                                       | 保留，挂在展开后的目录上                                                                    |

课程 ID、题目顺序、进度和后端都不改，改的只是呈现和导航。

```
总览：六段螺旋（六个学科）
  → 点一下：聚焦一个学科
    → 再点一下：展开成流动的丝带（一股一个方向，一段一章）
      → 选一章：这一段薄片化作流星飞到右边，组装成这一章的标本
        → 开始学习：宽正文 + 可收起的观察区 + 原题练习
          → 换一章：标本散回丝带，再组装成下一章
```

## 三、档案阵列：螺旋本身就是目录

Yank 一直觉得正式站的「课程档案阵列」很牵强。露娜在正式站 v2.50.0 上重新走了一遍：打开化学和数学、抽出档案，电脑 1440×900 和手机 390×844 都看了，问题大概有这几条。

### 为什么牵强

1. **画面断开了**：首页是一条流动的螺旋，一点学科，螺旋整个消失，换成灰色条纹地面和一排白色厚板。前后看不出是同一个东西。
2. **3D 卡片没在表达信息**：板上的字是斜的，又小，读不清；每张都长得一样，看不出学到哪、掌握多少。真正的信息全在右边的面板里，3D 只是在重复一份列表。
3. **规模撑不起「档案库」**：数学 5 张、物理只有 1 张，摆成一整个仓库会显得空。
4. **步骤多**：选卡 → 抽出档案 → 开始学习，三步才进课。「抽档案」是文件柜的比喻，和学习本身不太搭。
5. **手机上**：卡片占了半屏，却给不出信息。

### 改成什么

1. **不换场景**：点一个学科，螺旋上属于它的那一段转到前面。再点一下，这一段的薄片按章分组、松开排开，一组就是一章；有几个方向就分几股（化学三股）。从头到尾都是同一条螺旋。
2. **一片薄片 = 一道题**：正式站 17 个单元每章都正好 5 道题（共 85 道，按 `content.js`、`chapters.js`、`foundation-chapters.js` 核对过），所以每章用 5 片：
   - 这道题最近一次答对：象牙白；还没掌握：石墨色；
   - 正文读完：这一组边上亮一道细细的黄绿线；
   - 有到期要复习的题：那一片轻轻闪一下。

   扫一眼就知道每章学到哪。以后有章节不是 5 道题，就按实际题数给片数。

3. **字不印在 3D 上**：章节名用首页那种引线标签，是网页文字，清楚好读，键盘和读屏都能用。
4. **少一步**：悬停是预览，点一下打开详情（概述、学习记录、访问日志、先修），详情里直接就是「开始学习」，Enter 也能直接进。「抽出」可以保留成一个小动画，不再单独算一步。选中以后，这组 5 片就是第四节里飞去组装标本的那批薄片。
5. **背景**：去掉条纹地面，换成安静的深石墨和一圈很淡的测量环，和第五节的背景建议一致。
6. **手机**：螺旋缩成屏幕上方的一条带子，每章一小格、能看出进度；下面是真正的章节列表。
7. **全部保留**：课程 ID、⌕ 内部档案检索、按科目筛选、详情的三个页签、访问日志、键盘操作（←→ 换方向，↑↓ 换章）。

**建议**：正式站的档案阵列先保持原样，不继续修，因为它迟早会被大螺旋取代。在沙盒的大螺旋里一次做对，以后接入正式站时直接替换 `room.js` 的档案模式（`roomArchive*`）和 `room-scene.js` 的 `buildArchive` / `poseArchive`，数据仍然来自 `course-archive.js`。

## 四、核心机制：同一批薄片组装成不同的标本

> 2026-11-04：已做成小样，见 [meteor-assembly.md](meteor-assembly.md)。小样里展开后不再是丝带，而是沿测量环流动；组装时先流到入口再一股流进来。

- **同一批薄片**：螺旋、丝带和标本共用一批实例（`InstancedMesh`，数量固定）。每个标本给出每片的目标位置、朝向、大小和色调；用不上的薄片留在丝带里继续流动。v32 说观察区复用同一个 canvas，正好接得上。
- **组装**：每片沿一条弯曲的路径，从丝带飞向自己的目标位置，起飞时间错开。速度快的时候沿运动方向拉长、带一点渐隐的尾巴，看起来就像流星。整段约 1.2–1.6 秒，停稳后停止绘制（沿用按需渲染）。
- **拆散 / 换章**：先散回丝带，再组装下一章。中途换章就从当前状态改写目标，不重新播放整段，和 v31「保留速度的可逆阻尼」是同一个思路。
- **组装完以后**：标本不再动，可以拖动旋转；滑杆只改动受影响的那几片。例如定积分把 n 调大时，薄片在原地变细、补齐，不再重新播放流星。
- **关闭动效 / 系统减少动画**：直接换成下一章的标本。**没有 WebGL**：沿用 v32 的降级。
- **一章一份配置**：不给每章单独建模型，而是做一套可以拼装的「标本零件」，每章只写一小段配置（画哪个函数、取值范围、开放哪几个滑杆）。

### 各章的标本（按正式站 17 个单元）

| 方向                   | 单元                       | 标本（薄片组装成什么）                                          | 零件             |
| ---------------------- | -------------------------- | --------------------------------------------------------------- | ---------------- |
| 数学                   | 导数与切线斜率             | 薄片排成一条曲线；拖动步长 h，割线转成切线                      | 曲线 + 点        |
|                        | 定积分                     | 曲线下面立着一排薄片，越分越细，面积逼近积分                    | 一排薄片         |
|                        | 指数、对数与链式法则       | eˣ 和 ln x 隔着 y = x 互为镜像；拖 x，两个斜率相乘              | 曲线 × 2         |
|                        | 偏导数与全微分             | 直接是本章的 f = x²y 和 (2,3) 处的切平面；df 和 Δf 两条竖线并排 | 曲面 + 平面      |
|                        | 复数与概率归一化           | 复平面上几支箭头；箭头长度的平方变成柱高，归一化后加起来是 1    | 箭头 + 柱        |
| 经典物理               | 受力、功与能量             | 斜面和力的箭头；沿路径累积的功是一排薄片（和定积分同一个零件）  | 箭头 + 薄片      |
| 物理化学（可沿用）     | 自由能、反应商与平衡       | G 随反应进度的曲线，最低点就是平衡；拖 Q 看方向                 | 曲线 + 点        |
|                        | 氧化还原、原电池与电解     | 两个半电池的电势梯子，电子沿导线流动                            | 能级条           |
|                        | 能斯特方程与化学平衡       | E 随 lg Q 变化的直线，和上一章的梯子连起来                      | 曲线             |
|                        | 一级反应动力学             | 一排薄片按指数衰减变短；切到 ln c 就变成直线                    | 一排薄片         |
|                        | 波函数与位置概率           | ψ 的曲线和 \|ψ\|² 的薄片，面积等于概率（和复数那章呼应）        | 曲线 + 薄片      |
|                        | 一维势阱：边界与能级       | 一个阱，里面是能级横条，每层一条驻波                            | 能级条 + 曲线    |
| 有机（**要重新设计**） | 成键、杂化与官能团         | 球棍分子、杂化轨道的朝向                                        | 需要新零件       |
|                        | 电子效应、酸碱与共轭稳定性 | 共轭体系上的电子密度、弯箭头                                    | 需要新零件       |
|                        | SN2 与 SN1                 | 反应过程分步播放，背面进攻和碳正离子两条路线                    | 需要新零件       |
| 无机（**要重新设计**） | 从粒子到物质的量浓度       | 粒子数和体积，浓度是密度                                        | 需要新零件       |
|                        | 电子排布、离子与周期性     | 轨道能级条逐层填电子；周期表的趋势                              | 能级条（可沿用） |

有机和无机需要「原子 / 键」这类新零件，薄片很难拼成像样的球棍分子，可能要另加一批球形实例。建议先做数学和物理化学，有机、无机等 Yank 想清楚怎么互动再动手。实在不适合用图形讲的章节，就不硬配模型，中间放这一章的档案卡本身。

## 五、展开后的丝带与背景

- **丝带**：展开到最后不再停成三条静止的带子，而是松开成几股慢慢流动的薄片流，在标本周围前后错开。股数等于这个学科的方向数，数学一股，化学三股。流速很慢，停在那里时也不会抢正文的注意力。
- **背景**：Yank 说要换。露娜个人的感觉是，v32 的暗墙加龙门架有点像摄影棚的器材架，和「流动的丝带」放在一起会有点硬。可以考虑去掉龙门架，换成深石墨的空间，标本脚下放一圈很淡的测量环，四周保留和脊柱一致的细刻度。具体怎么做由特蕾莎来定。

## 六、脊柱区：大脑解剖和神经递质（文档里还没写）

Yank 说这件事和特蕾莎讨论过，但不确定有没有写进文档。露娜查了一遍沙盒的文档和代码，**还没有找到**，只有 v32 交接里一句「生命解剖元素是既有区域的视觉 / 观察方向」。请特蕾莎把讨论的结论补进文档。

露娜这边知道的情况：2026-11-01 Yank 提到「记忆星图」那种设计，模拟大脑，有海马体、杏仁体、前额叶，还有多巴胺、去甲肾上腺素、血清素、皮质醇这些神经递质。Yank 说「这个设计不是什么项目，就是看到了生物学上的大脑解剖和神经递质，觉得很酷，想放进去」。现有的记忆生命体 ZH-01 里，「背单词」对应的就是大脑（见 [living-specimen.md](../recall/living-specimen.md)）。

露娜的一个建议，只供讨论，要等 Yank 和特蕾莎来定：

- **脑区按单词的记忆阶段来对应**（背单词页里的大脑）：
  - 前额叶：正在回想的这一张卡（工作记忆）；
  - 海马体：今天新学、还在巩固的词；
  - 皮层：已经稳定记住的词。「从海马体到皮层」本身就是记忆巩固的真实说法；
  - 杏仁体：反复忘、需要特别标记的难词。
- **递质读数用真实的复习数据来驱动**，和现在的「模拟脉搏」一样，明确标为示意：
  - 多巴胺：答对、连对时的一次脉冲；
  - 去甲肾上腺素：到期压力和专注程度（待复习数）；
  - 血清素：节律是否稳定（连续复习的天数）；
  - 皮质醇：过载（脊柱现在已经有过载彩蛋）。
- **准确性**：皮质醇是激素，不是神经递质。标题写成「神经递质与激素」比较准确。和现有的生命体设定一样，要注明这是界面叙事的隐喻，不是医学模型。
