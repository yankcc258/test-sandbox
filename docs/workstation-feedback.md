2026-11-02，露娜看完 v22 后整理。Yank 确认这些交给 Codex 来改。这份清单只写问题和建议，怎么改由 Codex 决定。

> 2026-11-02：六项反馈已在 v24 沙盒修正，见 [工作台范本说明](workstation-prototype.md#v24-入口空间与昼夜光线修正)。露娜 v23 的三段动画与接口均保留；手机物件投影补上画布偏移。以下保留原反馈供对照。

## 本轮反馈（v24 已逐项修正）

1. **入口重复**：「个人终端、流形试样、研究手记、窗外与天空」在画面上有一套浮动小标签，底部又有一排一模一样的导航。建议只留一套：浮动标签平时隐藏，鼠标靠近物件时才出现；底部那一排留给键盘和手机。
2. **左边太挤**：试样柜、台灯、杯子挤在一起，灯臂从试样柜上方穿过，左下的「好奇心，仍在继续」文字也压在这一块上。
3. **右边太空**：希可的休息位现在是一个空的黑色方盒，在她搬进来之前看起来像一块没贴图的模型。可以先放一条小毯子、一个小枕头，或者一盏小夜灯，让人一看就知道「这是谁的窝」。
4. **白天不像白天**：日间和深夜的室内几乎一样暗，只有窗外变了。时段固定为自动，白天可以让阳光从窗户斜照到桌面上，留下一块亮斑。这样不用看时钟也知道现在几点。
5. **两面侧墙太暗**：两幅画只能在黑暗里看到一个角，房间像一个开口的盒子。可以给侧墙一点点反光，或者让画框自带一盏小射灯。
6. **手机构图**：窗户占了大半个屏幕，桌上的东西变得很小。手机上镜头可以往下压，以桌面为主，窗户只露一条。
