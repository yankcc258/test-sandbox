# 希可搬进工作台 · v27

2026-11-03 · 露娜。只改了 test-sandbox，正式站没动。基于 `6f6e688`（Codex 的 v26：弧形休息舱、桌旁对话）。

希可（鲸鱼娘女仆）是 Yank、特蕾莎和露娜一起做的角色。这一轮让她在沙盒里「住」下来：表情、台词和记仇本都沿用正式站的桌宠（`pet-life.js`、`pet-grudge.js`、`pet-lines.js`），立绘原样复制自正式仓库的 `art/pet/maid/`，放进三维场景里。

## 她一天怎么过

| 时间                    | 在哪           | 做什么                                                                                                                        |
| ----------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 白天（东京 6:00–23:00） | 工作台         | 在桌上跳来跳去：平板右边、研究手记上（看书）、窗台纸飞机旁、自己的小窝。每 15–35 秒换一个地方，跳的时候有弧线，用跑步的立绘。 |
| 白天，偶尔              | 实验室、复习区 | 「偶遇」：进页面 3.5 秒后，有 30% 的机会从屏幕左边或右边探头，走进来说一句话（叫你背单词、喝水），26 秒后跑回工作台。         |
| 深夜（东京 23:00–6:00） | 工作台 · 小窝  | 钻进 Codex 做的休息舱睡觉，头上冒 Z，偶尔说梦话。实验室和复习区晚上不会遇到她。                                               |

偶遇不会太频繁：同一个浏览器标签里，两次偶遇至少隔 10 分钟。

## 戳她、摸她、记仇本

| 操作                                       | 她的反应                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 点一下（戳）                               | 弹一下，说一句吐槽。正在被戳的时候她不会跳走。                                                  |
| 6 秒内连戳 6 下                            | 警告一次。警告后 15 秒内再戳：**记仇本记 1 分**（「连戳到生气」）。                             |
| 睡着时戳                                   | 迷迷糊糊推起眼罩。12 秒内再戳：彻底吵醒，**记仇本记 1 分**（「睡觉被戳醒」），14 秒后又睡回去。 |
| 摸头：鼠标在她身上来回划；手机上按住左右蹭 | 开心。有欠账时划掉一笔（每天最多还 3 分），全还清了会啪地合上本子。                             |
| 长按 0.5 秒 / 右键                         | 翻开记仇本：每一笔的时间、原因、还欠多少。                                                      |

- 同一种账 10 分钟内只记一次，和正式站一样。
- 沙盒的记仇本只存在这个浏览器的 `localStorage`（`zhixu-sandbox-grudge`），和正式站的记仇本无关。

## 和 Codex 的「希可 · 聊聊」怎么分工

- **点希可本人**：戳、摸、记仇本（这一轮，露娜）。
- **点小窝或底部「希可 · 聊聊」**：镜头靠近休息舱，打开桌旁对话（v26，Codex）。对话打开时，桌上的希可先藏起来，避免和对话面板重叠。
- 平板打开、纸飞机飞行、区域竖井、物件详情打开时，她也会暂时藏起来。

## 文件

| 文件                             | 内容                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| `sandbox/seeko.js`               | `createSeeko({ region, spots, motion, hidden })`：作息、跳跃、偶遇、戳/摸/记仇本、台词     |
| `sandbox/seeko.css`              | 立绘、气泡、弹一下/生气/Z、偶遇时的探头和走进走出、手机和减少动画                          |
| `assets/seeko/`                  | 18 张 220px 透明立绘（女仆装），来源见目录里的 README                                      |
| `workstation/luna.js`            | 工作台这一侧：她能站的四个位置跟着 3D 物件在屏幕上的投影走（`zxStation.anchor`），远小近大 |
| `recall-spine.js`、`recall.html` | 实验室、复习区的偶遇                                                                       |

Codex 的文件这一轮没有改。

**测试用的网址参数**：`?seeko=day`（强制白天）、`?seeko=night`（强制深夜）、`?seeko=meet`（实验室/复习区必定偶遇）、`?seeko=off`（不出现）；偶遇时 `&seekoSide=left|right` 指定从哪边出来。页面里还有 `zxSeeko.state`、`zxSeeko.move('desk' | 'notes' | 'sill' | 'nest')`、`zxSeeko.openBook()`、`zxSeeko.sleepNow()`。

## 验证

- `npm run check` 全部通过。
- Chromium 实际操作（桌面 1440×860、手机 390×844 触屏，软件渲染），没有脚本错误：
  - 白天：四个位置都落在对应物件上；戳一下有台词；连戳 7 下记 1 分；鼠标来回划摸头还清。
  - 深夜：睡在休息舱的床上；戳醒→再戳，记 1 分（「睡觉被戳醒」）。
  - 戳希可本人不会打开 Codex 的桌旁对话。
  - 实验室、复习区（左、右两边）偶遇；复习区左边改站在心电图那条线上，不压住左下的系统目录。
  - 手机：按住左右蹭能摸头。
